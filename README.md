# 📚 Study Buddy

**Study Buddy** is an AI-powered web application designed to help students study, understand, and revise faster, especially during exam preparation.

It combines multiple AI-powered study tools in one simple platform, allowing students to summarize study materials, understand online content, and ask questions through an interactive chatbot.

## ✨ Features

* 📄 **AI PDF Summarizer**
  Upload study PDFs and get concise summaries of important content.

* 🌐 **Webpage Summarizer**
  Summarize online webpages and extract the key information quickly.

* 🤖 **AI Study Chatbot**
  Ask questions, clear concepts, and get study-related assistance through an interactive chatbot.

* ⚡ **Faster Revision**
  Helps students quickly understand lengthy study materials and focus on important concepts.

* 🎯 **Exam-Focused Learning**
  Designed to support students during exam preparation and last-minute revision.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* AI / NLP
* Web Technologies

## 🚀 How It Works

1. Open the Study Buddy website.
2. Choose the required study tool.
3. Upload a PDF or provide webpage content.
4. Get an AI-generated summary or ask questions using the chatbot.
5. Use the generated information for quick learning and revision.

## 🎓 Use Case

Study Buddy is particularly useful for students who need to:

* Revise large amounts of study material quickly
* Understand difficult topics
* Extract important points from PDFs
* Summarize lengthy webpages
* Get quick answers to study-related questions
